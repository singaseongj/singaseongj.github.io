매력점수 계산식 (쉽게 보기)

이 페이지는 recommendations.json의 점수(= fetchStockInfo.js가 산출한 점수)와 tools/buildPoolsTrendy.js의 계산 근거를 함께 보여줍니다. 섹션별 상위 5개 종목이 왜 높은 점수를 받는지 쉽게 설명합니다.

0) pools-metrics 전체 반영 공식 (현재 fetchStockInfo 기준)

normalizedRaw = clamp(rawScore, 0, 100) / 100
numericNorm(x) = x≥0 ? (tanh(|x|)+1)/2 : (1-tanh(|x|))/2
allSignalAvg = pools-metrics 엔트리의 모든 숫자값(중첩 객체/배열 포함)을 numericNorm 후 평균
boolSignalAvg = pools-metrics 엔트리의 모든 불리언값을 (true=1, false=0)로 평균
coverageBoost = clamp((numericCount + boolCount) / 80, 0, 1)
composite = 0.45*normalizedRaw + 0.35*allSignalAvg + 0.10*boolSignalAvg + 0.10*coverageBoost
finalScore = round(clamp(80 + (composite^0.7)*20 + jitter, 80, 100))

즉, 모든 pools-metrics 신호를 통합하면서도 최종 매력점수는 80~100 구간에서 표현됩니다.

1) 점수 계산 핵심 구조

인기도(pop01) = (뉴스 + 네이버인기 + 네이버금융 + 모멘텀 + 블로그 + 위키 + 긍정키워드 - 부정키워드) / 가중치합
기본점수(base01) = 안전주: size 가중치 × 시가총액점수(size01) + (1-size 가중치) × 인기도(pop01) / 공격주: 인기도(pop01) 중심(시가총액 제외)
최종 totalScore(0~100) = 보정(피드백/신뢰도/누락데이터/국내시장 패널티 등) 후 0~100 구간으로 변환

즉, 안전주는 크기(시총)+관심도, 공격주는 관심도 중심으로 계산하고, 데이터 신뢰도/시장 보정을 더해 최종 점수를 만듭니다.

2) 각 항목 의미 (간단 버전)

  • newsScore: 최근 뉴스가 얼마나 많은지/강한지
  • naverPopularity, naverFinanceScore: 네이버 관심도와 금융 문맥 연관도
  • trend/momentum: 최근 추세가 좋아지는지
  • blog/wiki: 대중 관심(블로그/위키 조회)
  • posHits / negHits: 긍정·부정 키워드 비율
  • size01: 시가총액 기반 안정성/규모 점수
  • sourceReliability / confidence: 데이터 품질 보정

3) 섹션별 상위 5개 종목

표의 점수는 recommendations.json에 저장된 점수(= fetchStockInfo 계산 결과)입니다. 계산 근거 설명은 기존과 동일합니다.
