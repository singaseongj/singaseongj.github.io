0️⃣ 전체 반영 공식

금융 = 0.25×ret5 + 0.25×ret20 + 0.15×저변동성 + 0.20×turnover + 0.15×ADV
뉴스 = 0.30×뉴스량 + 0.40×newsScore + 0.20×sentiment + 0.10×googleNews
네이버 = 0.35×인기도 + 0.25×ASVI + 0.20×뉴스량 + 0.15×스파이크 + 0.05×품질보너스
콘텐츠 = 0.40×blog + 0.35×wiki + 0.25×wikiViews(log)
품질 = (0.50×reputation + sourceReliabilityBonus + eligibilityBonus) / 0.65
composite = 통합점수 신뢰도(confidence)>0.7 이면 Unified 35% 우선, 아니면 5개 축 가중합

1️⃣ 점수 계산 핵심 구조

인기도(pop01) = (뉴스 + 네이버인기 + 네이버금융 + 모멘텀 + 블로그 + 위키 + 긍정키워드 - 부정키워드) / 가중치합
기본점수(base01) = 안전주: size 가중치 × 시가총액점수(size01) + (1-size 가중치) × 인기도(pop01) / 공격주: 인기도(pop01) 중심(시가총액 제외)
최종 totalScore(0~100) = 보정(피드백/신뢰도/누락데이터/국내시장 패널티 등) 후 0~100 구간으로 변환

2️⃣ 각 항목 의미

  • Financial: ret5/ret20(모멘텀), vol20(리스크), turnover/adv20(유동성)
  • News & Sentiment: 뉴스량 최적 구간, newsScore 품질, 감정도/긍부정 단어
  • Naver Ecosystem: naverPopularity, naverAsvi, naverSpike/naverPersist, naverCount
  • Blog & Wiki: blogScore·blogMentions, wikiScore, wikiViews 로그 정규화
  • Reputation & Quality: reputationScore, sourceReliability, eligible 조건 보너스
  • Unified Score: unifiedScoreData(score/confidence)가 충분히 신뢰될 때 핵심 가중치로 반영
